# v2.5.0

发布日期：2026-09-12

## 概述

本版本围绕「导出的表格能否直接使用」补充三项能力：冻结首行、自动筛选与数据验证下拉列表。三项均默认关闭，`.xls` 与 `.xlsx` 同样支持。

## 变更明细

### 1. 新增：冻结首行与自动筛选

行数较多时，滚动工作表会使表头移出可视区域；使用筛选亦需手工选定区域。两个选项各自解决其中一项。

```csharp
var bytes = ExcelHelper.ObjectToExcelBytes(orders, options =>
{
    options.FreezeHeader = true;   // 滚动时表头保持可见
    options.AutoFilter = true;     // 表头附带筛选下拉
});
```

筛选区域覆盖表头及本次写入的数据行。以 `AppendObjectToExcelBytes` 追加的工作表各自独立，不影响工作簿中已有的工作表。

### 2. 新增：数据验证（下拉列表）

固定取值声明于特性，运行时方可确定的取值通过 `options.Dropdowns` 传入，后者优先。

```csharp
public class Order
{
    [ExcelColumn("状态", Dropdown = new[] { "待付款", "已发货", "急件", "已取消" })]
    public string Status { get; set; }

    [ExcelTitle("城市")] public string City { get; set; }
}

var bytes = ExcelHelper.ObjectToExcelBytes(orders, options =>
{
    options.Dropdowns["城市"] = cities.Select(c => c.Name).ToArray();
});
```

Excel 将拒绝列表之外的输入。若列表总长超过 255 字符，或取值中含有逗号、引号，则 Excel 的行内列表无法容纳：此时取值改写入一张隐藏工作表，由一个定义名称指向该区域，下拉引用该名称。采用定义名称而非直接跨表引用，是因为 `.xls` 的数据验证不支持跨表引用，而 `.xls` 恰为默认格式；此前这类列表在 `.xls` 上会直接抛出异常。

无数据的导出同样会在首行附带下拉，便于作为填写模板分发。

### 3. 新增：`AppendObjectToExcelBytes` 的 options 重载

追加工作表时亦可设置冻结、筛选、下拉及其他全部选项。

```csharp
var bytes = ExcelHelper.AppendObjectToExcelBytes(sourceBytes, rows, options =>
{
    options.SheetTitle = "第二页";
    options.FreezeHeader = true;
});
```
