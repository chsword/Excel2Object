# v2.11.0

发布日期：2026-09-16

## 概述

本版本新增流式导入：逐行读出 `.xlsx` 的一张工作表，不把整个工作簿建进内存。上一版让导出不再受行数牵制，这一版补上读的一侧。为此，导入的类型转换与 NPOI 的单元格解耦，整份读入与逐行读出共用同一套转换。

## 变更明细

### 1. 新增：流式导入

此前的导入一律先把整个工作簿读进内存：`WorkbookFactory.Create` 会为每一格建一个对象，二十万行的文件因此要占用一吉字节以上。

新增的 `ExcelStreamToObject` 逐行读出：

```csharp
using var file = File.OpenRead("orders.xlsx");
foreach (var order in ExcelHelper.ExcelStreamToObject<Order>(file))
    Handle(order);
```

`ExcelImporter` 上有同名的实例方法，选项与既有入口一致（`SheetTitle`、`TitleSkipLine`、`OnCellError`）：

```csharp
var errors = new List<ExcelImportError>();
using var file = File.OpenRead("orders.xlsx");
var orders = new ExcelImporter().ExcelStreamToObject<Order>(file, options =>
{
    options.SheetTitle = "本月";
    options.OnCellError = errors.Add;
});

foreach (var order in orders) Handle(order);   // 取一行、转一行
```

取到的序列是惰性的：取一行、转一行，读过的行随即可以回收。`Take`、`Where` 一类的操作因此真的能少读——取够了便不再往下读。

本机实测（五列，含文本、金额与日期，net8.0）：

| 行数 | 整份读入 | 流式导入 |
| --- | --- | --- |
| 5 万 | 393 MB / 3.1 秒 | 103 MB / 1.1 秒 |
| 20 万 | 1265 MB / 8.4 秒 | 194 MB / 2.9 秒 |

两种方式读出的数据逐字段一致（实测中以求和校验）。流式导入快出一截，是因为不必先为每一格建一个对象。

需要说明的是，流式导入的内存并非常数：文件中的共享字符串表会整个留在内存里（Excel 把重复的文本收在那里），调用方自己攒下的对象也照样占内存。省掉的是「每一格一个对象」这一份。

### 2. 与整份读入的三处不同

- **公式格读的是文件中存着的上一次计算结果**，而非当场求值。Excel 存盘时会写下这个结果，故 Excel 保存过的文件照常读出；本库导出的文件里公式没有这个结果（要等 Excel 打开时才算出），此时该格读作空白——与其他空白格一样：写进可空列得到 `null`，写进非可空的数值列则照旧以转换失败中止，这一点两条路相同。整份读入的那条路仍会当场求值，行为不变。
- **只有 `.xlsx` 能够逐行读出。** 传入 `.xls` 时会照旧整份读入内存，结果一致——该格式的数据并非顺序存放，无从逐行取出。
- **工作表要在一开始就定位。** 表名写错时当场抛出 `Excel2ObjectException`，而不是等到取第一行。

传入的流由本方法读取，遍历结束或中途放弃时关闭其上的工作簿。与 `File.ReadLines` 一样，取到的序列须被遍历——只取不用则文件不会被关上。

### 3. 内部：导入的类型转换不再依赖 NPOI 的单元格

导入的类型转换原本直接写在 `ICell` 之上，而逐行读出拿到的是原始的 XML，并没有单元格对象。现把两者都归到内部的 `IImportRow` 与 `CellData` 上：一格读到的东西与它从哪里来无关，转换那一套因而只有一份，两条路的行为不会各自漂移。

## 行为变更

以下几处对既有入口同样生效，均为读取行为的收敛，不影响正常的导入结果：

- **字典形式的导入改为惰性给出。** `ExcelToObject<Dictionary<string, object>>` 此前先把全部行收成一个 `List` 再返回，现与模型形式一致，逐行给出。
- **标题行中同名的标题以最左边那一列为准。** 此前字典形式遇到重复标题会抛出 `ArgumentException`（`ToDictionary` 的行为），现与模型形式的做法一致。
- **标题行中的非文本单元格不再中断导入。** 此前取标题时直接取字符串值，遇到数值标题会抛出异常；现读作它显示的文本，对不上的列照旧忽略。
- **日期序列号超出 Excel 日历时上报的异常改为本库抛出的 `ArgumentException`**，并写明该序列号；此前上报的是 NPOI 抛出的异常。该单元格仍取 `null`，导入继续。
