# v2.7.0

发布日期：2026-09-13

## 概述

本版本引入样式表，样式可按作用范围声明，而非在每个 `[ExcelColumn]` 上重复书写；同时补充单元格背景色、边框、自动换行、垂直对齐等此前缺失的能力，并支持以十六进制书写颜色。

## 变更明细

### 1. 新增：样式表 `options.Styles`

样式按作用对象声明，分为表头、全体单元格、指定列、奇数行与偶数行五种范围。

```csharp
var bytes = ExcelHelper.ObjectToExcelBytes(orders, options =>
{
    options.Styles
        .Header(s => s.Bold().Background("#4472C4").Color("#FFF").Center())
        .Cells(s => s.Border("1px solid #D0D0D0"))
        .EvenRows(s => s.Background("#F2F2F2"))
        .Column("金额", s => s.Format("#,##0.00").Right())
        .Column("备注", s => s.Wrap().VerticalAlign(ExcelVerticalAlignment.Middle));
});
```

可设置的属性包括：`Color` 与 `Background`、`Bold` / `Italic` / `Underline` / `Strikeout`、`FontFamily` 与 `FontSize`、`Left` / `Center` / `Right` / `Align` / `VerticalAlign`、`Wrap`、`Format`，以及 `Border` 与 `BorderTop` / `BorderRight` / `BorderBottom` / `BorderLeft`。

### 2. 层叠规则

各层按由宽至窄的顺序叠加，且仅显式设置的属性参与叠加，因此各层之间为补充关系而非互相替换：

```
Cells → OddRows / EvenRows → [ExcelColumn] 特性 → Column("标题")
```

`Header(...)` 位于特性的 `Header*` 属性之下，规则相同。一旦声明了表头样式，「带 `[ExcelColumn]` 的表头默认 10pt」这一历史行为即让位，整行表头字号保持一致。

### 3. 新增：背景色与边框

此前单元格既无背景色也无边框，仅条件格式可设置背景色。边框的书写方式与 CSS 一致：

```csharp
options.Styles
    .Cells(s => s.Background("#FFFFFF").Border("1px solid #D0D0D0"))
    .Column("金额", s => s.BorderBottom("2px dashed #FF0000"));
```

### 4. 新增：十六进制颜色

颜色可写为 `#RRGGBB` 或 `#RGB`，不再局限于 `ExcelStyleColor` 的 56 色枚举。

- `.xlsx` 直接保存所写的颜色；
- `.xls` 仅有 56 色调色板，按 CIELAB 感知距离选取最接近的一色。采用感知色彩空间而非 RGB 距离的原因在于：NPOI 自带的匹配会将浅灰 `#D9D9D9` 匹配为淡紫 `#CCCCFF`，RGB 欧氏距离与 redmean 加权同样会选中淡紫或淡绿，仅在感知色彩空间中方可得到灰色。
- 以 `ExcelStyleColor` 指定的颜色在两种格式下仍按调色板索引写入，语义与既有版本一致。

因 `.xls` 调色板中缺少极浅的灰，`#F2F2F2` 将匹配为白色；在该格式下实现隔行底色，建议使用较深的灰，例如 `#C0C0C0`。

### 5. 改进：列级样式对任意列类型生效

在 `Column("标题")` 上声明的样式适用于任何列类型，数值列由此可设置 `Format("#,##0.00")`。特性上的 `Format` 仍仅作用于日期列，以保持兼容。

### 6. 改进：外观相同的单元格共用样式

样式核心重构为解析器与工厂两部分，单元格样式与字体均按其内容作键缓存。隔行底色等场景不会随行数增长而突破 `.xls` 的 4000 个样式上限。

## 升级影响

既有导出的外观不变：未声明样式表时，输出与 v2.6.0 相同。
