# v2.6.0

发布日期：2026-09-12

## 概述

本版本新增条件格式。与 `[ExcelColumn]` 上的样式不同，条件格式写入的是规则而非固定外观，规则由 Excel 求值，数据被编辑后颜色随之变化。

## 变更明细

### 1. 新增：`options.ConditionalFormats`

规则以列为单位声明，可使用比较运算符，亦可直接书写 Excel 条件表达式。

```csharp
var bytes = ExcelHelper.ObjectToExcelBytes(orders, options =>
{
    // 金额大于一万时字体标红并加粗
    options.ConditionalFormats.Add(new ConditionalFormat("金额")
    {
        Operator = ConditionalOperator.GreaterThan,
        Value = 10000,
        FontColor = ExcelStyleColor.Red,
        Bold = true
    });

    // 状态为「急件」时整行填充黄色
    options.ConditionalFormats.Add(new ConditionalFormat("状态")
    {
        Operator = ConditionalOperator.Equal,
        Value = "急件",
        WholeRow = true,
        BackgroundColor = ExcelStyleColor.Yellow
    });

    // 亦可直接书写条件，按第一行数据（第 2 行）书写，列以 $ 锁定
    options.ConditionalFormats.Add(new ConditionalFormat("金额")
    {
        Formula = "$B2>$C2",
        BackgroundColor = ExcelStyleColor.LightGreen
    });
});
```

### 2. 支持的运算符与取值

运算符包括 `Equal`、`NotEqual`、`GreaterThan`、`LessThan`、`GreaterThanOrEqual`、`LessThanOrEqual`、`Between` 与 `NotBetween`，后两者以 `Value2` 给出区间的另一端。

`Value` 按其类型写成 Excel 字面量：数值原样写入，字符串加引号（内部引号按 Excel 规则转义），`DateTime` 写为 `DATE(y,m,d)`，布尔值写为 `TRUE` 或 `FALSE`。

### 3. 整行高亮的实现方式

Excel 的单元格比较规则仅作用于规则所在的单元格。因此当 `WholeRow` 为 `true` 时，比较会转写为锚定该列的表达式（例如 `$B2>10000`），并将应用范围扩展至整行。

### 4. 其他

同一列可声明多条规则，按声明顺序写入；空数据导出同样保留规则，便于制作模板；列标题不存在或比较缺少 `Value`、`Between` 缺少 `Value2` 时，抛出带有列标题与运算符的 `Excel2ObjectException`。`.xls` 与 `.xlsx` 均受支持。
