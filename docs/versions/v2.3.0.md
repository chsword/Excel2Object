# v2.3.0

发布日期：2026-09-11

## 概述

本版本将公式内置函数库由 34 个扩充至 334 个 Excel 函数，并修复公式生成与单元格样式方面的若干问题。函数清单另见 [ExcelFunctions.md](../../ExcelFunctions.md)。

## 变更明细

### 1. 新增：334 个内置函数

分为十类：数学与三角（73）、统计（80）、逻辑（11）、查找与引用（33）、日期时间（25）、文本（39）、信息（20）、财务（21）、工程（20）、数据库（12）。其中信息、财务、工程、数据库为新增分类，入口分别为 `ExcelFunctions.Information`、`.Financial`、`.Engineering`、`.Database`。

### 2. 新增：公式中可书写更多普通 C#

包括 `%`（MOD）、`^`（乘幂）、`&&` / `||` / `!`（AND / OR / NOT）、三元表达式（IF）、`Math.*`、`string` 成员（`ToUpper`、`Substring`、`Length`、`Contains` 等）、`DateTime` 成员与 `AddDays` / `AddMonths` / `AddYears`，以及可空属性的 `.HasValue`。

语义与 Excel 不完全一致的成员（如 `Math.Round`、`string.Trim`）不作翻译，需显式调用对应的 `ExcelFunctions` 函数。

### 3. 新增：公式中可引用捕获的变量与常量表达式

lambda 捕获的局部变量、`new DateTime(...)` 等常量表达式会先行求值并写为字面量。此前该类表达式会生成无效公式。

### 4. 改进：区间可用于接受单值的参数位置

`c.Matrix(...)`、`c.Columns(...)` 可隐式转换，`SUM` 等函数可混合传入单元格与区间。

### 5. 修复

- Excel 2007 之后新增的函数写入后打开显示 `#NAME?`：xlsx 要求此类函数存为 `_xlfn.IFS`、`_xlfn.STDEV.P`（`SORT` 与 `FILTER` 为 `_xlfn._xlws.`），现自动添加前缀。此前已支持的 `DAYS` 即受此影响。
- 公式中的数值按当前区域性格式化：`de-DE` 等区域下 `1.5` 会写成 `1,5`，导致公式无法解析。现统一使用不变区域性。
- 文本字面量中的双引号未按 Excel 规则转义（`"` 应写为 `""`）。
- `[ExcelColumn]` 的单元格样式被静默忽略：样式缓存键与分支判断不匹配，`CellBold`、`CellFontColor`、`CellAlignment` 等此前未写入单元格。同时修复某列声明 `CellAlignment` 会改动工作簿默认样式、导致其他列一并变化的问题（#47）。
- `FormulaResultType = typeof(DateTime)` 的公式列没有日期格式，在 Excel 中显示为 `46282.6` 一类的序列号（#47）。

## 不兼容变更

`IStatisticsFunction.Sum` 的参数由 `params ColumnMatrix[]` 改为 `params ColumnValue[]`，`IMathFunction` 多个方法的返回值由 `int` / `double` 统一为 `ColumnValue`。该变更为源码级兼容，既有公式无需修改即可编译，但二进制不兼容，升级后需重新编译。
