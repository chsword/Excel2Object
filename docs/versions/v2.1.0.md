# v2.1.0

发布日期：2026-09-08

## 概述

本版本使公式列支持跨工作表引用，并将依赖更新至 NPOI 2.8.0。

## 变更明细

### 1. 新增：公式列的跨工作表引用

```csharp
options.FormulaColumns.Add("单价", c => ExcelFunctions.LookupAndReference.VLookup(
    c["商品"], c.Sheet("Products").Matrix("名称", 2, "价格", 100), 2, false));
```

可用形式包括 `c.Sheet("Products")["Price", 2]`、`.Matrix(...)` 与 `.Columns(...)`，可直接用于 `VLOOKUP` 等函数。同时新增当前工作表的整列引用 `c.Columns("A列", "D列")`。详见 [ExcelFunctions.md](../../ExcelFunctions.md)。

### 2. 改进：引用不存在的列或工作表时抛出异常

此前会生成无效公式，现抛出 `Excel2ObjectException` 并附带公式列名。

### 3. 依赖与安全

- NPOI 更新至 2.8.0。NPOI 自 2.8 起附带 OSMF EULA，本库已在项目文件中声明接受；源代码仍为 Apache-2.0 许可。
- 修复传递依赖 System.Security.Cryptography.Xml 的安全漏洞，版本钉至 8.0.4。
- 移除未使用的 SixLabors.ImageSharp 依赖；补全 `FormulaColumnsCollection.CopyTo`；`ColumnValue.Equals` 与 `GetHashCode` 不再抛出异常。

### 4. 工程

持续集成与测试迁移至 .NET 10；修复发布流程中 GitHub Release 创建失败的问题。
