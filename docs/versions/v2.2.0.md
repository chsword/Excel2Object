# v2.2.0

发布日期：2026-09-11

## 概述

本版本新增命令行工具，并改进导出时的单元格类型判定与公式生成。

## 变更明细

### 1. 新增：命令行工具 `excel2obj`

支持 Excel 与 JSON 互转、批量转换，以及依据表头生成带 `[ExcelTitle]` 的模型类。详见 [Chsword.Excel2Object.Cli/README.md](../../Chsword.Excel2Object.Cli/README.md)（#9）。

```bash
dotnet tool install -g Chsword.Excel2Object.Cli
excel2obj convert data.xlsx data.json
```

### 2. 新增：公式列可通过模型属性引用列

```csharp
options.FormulaColumns.Add<Order>("Total", (c, m) => m.Price * m.Qty);
```

属性名在编译期检查，引用未导出的属性将抛出异常。详见 [ExcelFunctions.md](../../ExcelFunctions.md)（#22）。

### 3. 改进：按类型写入单元格

导出时数值列写为数字单元格，`bool` 列写为布尔单元格，`null` 与 `DBNull` 写为空白单元格；此前一律写为文本。字符串列仍为文本，前导零不会丢失。

### 4. 修复与改进

- 修复公式中运算符优先级导致括号缺失的问题：`c["A"] * (c["B"] + c["C"])` 此前生成 `A2*B2+C2`。
- 公式中引用当前工作表不存在的列标题时抛出 `Excel2ObjectException`，不再静默回退。
