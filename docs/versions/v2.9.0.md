# v2.9.0

发布日期：2026-09-13

## 概述

本版本新增合并单元格：既可让某列中连续相同的值自动并成一格，也可直接指定要合并的区域。

## 变更明细

### 1. 新增：按列合并连续相同的值

分组报表中同一省份、同一类别的若干行通常只需显示一次，此前只能导出后手工合并。

```csharp
var bytes = ExcelHelper.ObjectToExcelBytes(orders, options =>
{
    options.MergeRepeatedColumns.Add("省份");
    options.MergeRepeatedColumns.Add("城市");
});
```

规则如下：

- 仅**相邻且相等**的行参与合并，跨越其他取值的相同值不会并到一起；
- **空单元格不参与**：若干行都没有值，并不意味着它们属于同一组；
- 各列**彼此独立**判断。若需要「同一省份之下的城市才合并」这类层级语义，请自行保证数据已按层级排序；
- 数值按其值而非显示文本比较，格式不同但数值相同的两行仍会合并。

### 2. 新增：直接指定区域

```csharp
options.MergedRegions.Add("A1:C1");
```

写法不合法（例如 `A1-C1`）会在导出时抛出 `Excel2ObjectException` 并说明应有的形式。

### 3. 重叠区域会被拒绝

Excel 视重叠的合并区域为损坏文件。导出时若两个区域重叠，抛出 `Excel2ObjectException` 并指出与哪一个重叠，而非写出打不开的文件。

## 注意事项

- 被并入的单元格仍保留各自的值，Excel 只显示左上角那一个。因此导回对象时每一行的数据依然完整，与未合并时一致。
- Excel 中含合并单元格的区域无法排序。若同时启用 `AutoFilter`，筛选可用，排序会被 Excel 拒绝。
