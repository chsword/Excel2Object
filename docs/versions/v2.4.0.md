# v2.4.0

发布日期：2026-09-11

## 概述

本版本将 `DateTime` 列的导出由文本改为真正的日期单元格，并使 `[ExcelColumn(Format = ...)]` 的 .NET 格式串自动翻译为对应的 Excel 数字格式。相关说明另见 [DateTimeFormats.md](../../DateTimeFormats.md)。

## 变更明细

### 1. 新增：`DateTime` 列写为日期单元格

此前 `DateTime` 列写入的是文本，Excel 中排序按字典序进行，筛选不显示日期树，参与计算得到 `#VALUE!`。现写入的是日期单元格（序列号与日期格式），`null` 写为空白单元格。`Dictionary<string, object>` 与 `DataTable` 导出中的 `DateTime` 值同样处理。

```csharp
public class Order
{
    [ExcelColumn("下单时间", Format = "yyyy-MM-dd HH:mm")]
    public DateTime PlacedAt { get; set; }
}
```

| | v2.3 及以前 | v2.4.0 起 |
| --- | --- | --- |
| 单元格值 | 文本 `"2026-09-11 14:30"` | 数值 `46276.604` |
| 数字格式 | `@`（文本） | `yyyy-mm-dd hh:mm` |
| 排序 | 按字典序 | 按时间先后 |
| 参与公式 | `#VALUE!` | 正常计算 |

### 2. 新增：格式串自动翻译

`Format` 为 .NET 日期格式串，导出时翻译为显示效果相同的 Excel 数字格式，例如 `yyyy-MM-dd HH:mm:ss` 译为 `yyyy-mm-dd hh:mm:ss`，`yyyy年MM月dd日` 译为 `yyyy"年"mm"月"dd"日"`。未指定 `Format` 时使用 `yyyy-mm-dd hh:mm:ss`。已为 Excel 拼写的格式（`m/d/yy`、`[$-409]d-mmm-yy`、`yyyy/m/d;@`）原样使用。

时区偏移（`zzz`、`K`）与纪元（`g`）在 Excel 中无对应写法，将被丢弃。

### 3. 新增：`DateTimeAsText` 兼容开关

如需恢复 v2.3 及之前按文本导出的方式：

```csharp
var bytes = ExcelHelper.ObjectToExcelBytes(orders, options =>
{
    options.DateTimeAsText = true;
});
```

同时为 `DataTable` 导出新增接受 options 的重载：`ObjectToExcelBytes(DataTable, Action<ExcelExporterOptions>)`。

### 4. 修复：公式列接管日期列时丢弃公式

公式列按标题接管模型中已有的列时，若该列带有自定义 `Format`，此前会丢弃公式并改写模型自身的值为文本。现保留公式并套用日期格式。若公式返回数值而非日期，请以 `FormulaResultType` 声明。

### 5. 修复：日期单元格读为文本时得到序列号

日期单元格读入 `string` 属性或 `Dictionary<string, object>` 时，此前得到 `46276.6` 一类的序列号。现按单元格格式渲染为 `yyyy-MM-dd`、`HH:mm:ss` 或两者；`[h]:mm` 一类的经过时间仍按数值读取。数值属性（`double`、`decimal` 等）始终取原始数值。

## 行为变更

- Excel 的日历不覆盖 1900 年之前（采用 1904 日期系统的工作簿为 1904 年之前）。此类日期，尤其是未赋值的 `default(DateTime)`，仍按 `Format` 渲染为文本写入，以避免写出 Excel 显示为 `####` 的负数序列号。
- `hh` 不带 `tt` 时显示 24 小时制。Excel 没有不带 AM/PM 标记的 12 小时制。
- Excel 将分钟视为月份，除非其紧邻小时或秒。因此建议书写 `HH:mm` 而非 `HH时mm分`，后者中间的字面量会使 Excel 将其显示为月份。
