# v2.0.4

发布日期：2025-10-11

## 概述

本版本为 2.0.0.211 之后首个发布至 NuGet 的 2.0.x 版本（v2.0.1 至 v2.0.3 未曾发布），包含此期间的全部改动：自动列宽、日期时间格式的全面支持，以及发布流程的自动化。

## 变更明细

### 1. 新增：基于内容的自动列宽

```csharp
var bytes = ExcelHelper.ObjectToExcelBytes(orders, options =>
{
    options.AutoColumnWidth = true;   // 启用自动宽度
    options.MinColumnWidth = 8;       // 最小宽度（字符）
    options.MaxColumnWidth = 50;      // 最大宽度（字符）
    options.DefaultColumnWidth = 16;  // 未启用自动宽度时的默认宽度
});
```

宽度依据内容计算，并正确处理中文与其他 Unicode 字符的显示宽度。

### 2. 新增：日期时间格式的全面支持

导入时可识别 56 种日期时间格式，涵盖 ISO 8601（含时区与毫秒）、多种分隔符（横线、斜线、点号）、12 小时制与 24 小时制、仅时间格式，以及美国与欧洲等区域写法，并向后兼容既有的中文年月日格式。详见 [DateTimeFormats.md](../../DateTimeFormats.md)。

### 3. 依赖更新

NPOI 更新至 2.7.5；SixLabors.ImageSharp 更新至 3.1.11（修复安全漏洞）。

### 4. 工程

以 GitHub Actions 取代 AppVeyor；新增由 tag 触发的自动发布流程与 `release.ps1` 一键发布脚本。
